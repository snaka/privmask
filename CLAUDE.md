# privmask

## Where design documents live

**Design documents belong in GitHub Issues on this repository, not in files under `docs/`.**

Write the design as an Issue before implementing. `docs/` is for findings that
outlive a decision — measurements of what the Apple APIs and the on-device model
actually do — not for the reasoning that led to a change.

Examples to match: [#1](https://github.com/snaka/privmask/issues/1) for a
problem found by measurement, [#2](https://github.com/snaka/privmask/issues/2)
for a design proposal.

This is a per-repository choice, still being tried out. Other repositories may
keep design documents as files instead.
